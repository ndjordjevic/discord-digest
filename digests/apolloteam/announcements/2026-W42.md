### 📦 Release 1278x in internal testing, planned as long-term STABLE, with new ATARI core
biggun68080 announced Release 1278x is in internal testing, with betas hopefully on the website this week, bringing MAGGIE Version1 and a new ATARI core, intended as a long-lived stable release.

- Features: latest BTC branch prediction, two decoders with fusing, improved instruction predecode, latest TEX enhancement, lower-latency datacache, 64byte cache lines, two hardware Pip units, improved 256 color pointer sprite.

- ATARI core has the real Atari registers in correct locations and is recognized by the OS as Atari 060 Falcon.

### Planned BETA feature releases after stable: STRONG MAGGIE, MMU, FPU, 128bit AMMX

- STRONG MAGGIE should give about 3 times the 3D performance plus new features.
- FPU upgrade brings compiler-friendly 32 registers and 3 operation modes.
- Important features such as the MMU release will come out for both ATARI and AMIGA.
