### 📦 ApolloPointer 1.0alpha pointer editor released for V4
bodyprint released ApolloPointer 1.0alpha, an editor for the 40 OS3.2+ mouse pointers (32x32, 256 colours). tjomp confirmed it works on ApolloOS for the editor and direct install, not the P96 resident.

- Tested only on AmigaOS 3.2.3 and Icedrake by the author; Hardware > Install Pointer writes directly to V4 sprite hardware.
- ApolloOS uses Cybergraphics, not P96, so the resident program doesn't set pointers there.
- willemdrijver: hardware sprite is V4 only; ApolloOS and Coffin sagagfx drivers use it for the OS cursor.

❓ **Open:** Resident program needs to detect the RTG method (Cybergraphics) to work on ApolloOS.

### V4SA gray screen at boot with CF card solved by stronger power supply
bosstone100's V4SA showed a gray screen with a CF card across cores and images; .cibee suggested the power supply, and a different adapter fixed booting.

- Reflashing the CF, trying core 12840, and AROS/ApolloOS on SD didn't help; ApolloOS booted from SD.
- biggun68080 said a brief gray screen is normal; core 12842 is currently being tested.
- .cibee: 5.2V/1.8A adapter is within limits and a stronger plug poses no danger if voltage is right.
