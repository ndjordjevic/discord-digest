### Apollo team outlines 080 work: MMU, 32 registers, eMAC, faster AMMX
Asked about core changelogs, biggun68080 said only stable releases get descriptions, then listed current development: memory controller, MMU, register and instruction extensions, eMAC and AMMX improvements.

- Release descriptions are written only for full stable cores, not alpha/beta, and no public readme database is kept.
- Memory controller moves to 128-bit internally with 64-byte bursts, letting cache lines refill in a 4-clock burst, saving 4 cycles.
- MMU enabled (useful for Atari MiNT, needed for Linux); all 68k instructions support 32 data registers and 2- and 3-operand forms; Arne added the eMAC unit.

### Firebird V4 core 11350 with OS 3.2.3 loses Fast-RAM
theotheoderich found the Firebird core link dead on the German Apollo page; the English page link worked. After flashing 11350 and OS 3.2.3, Fast-RAM disappeared and the problem remained unresolved.

### V4 Standalone core 12846 breaks SD and CF card detection
maverick6787 and asktodd both lost storage detection after flashing STANDALONE_12846_x14_16; songoku5822 attributed the SD problem to sagasd.device in ROM, and tim3233 explained how to revert via USB Blaster.
