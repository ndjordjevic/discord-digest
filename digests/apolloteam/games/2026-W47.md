### 📦 OpenSWOS native Vampire V4 build released with online multiplayer
tommysammy released an open-source C rewrite of SWOS with a native V4 build at 50 FPS; after feedback from danyppc, a 640x480 option will be added.

- Features SAGA 960x540 with AMMX upscaling, native Paula sound, and GGPO rollback netcode for V4-vs-PC online play
- 640x360 was rejected because too much of the pitch would be cut off, and 1024x768 would drop below 50fps
- Requires your own SWOS copy for game data

### 📦 AmiScreamer v1.0 released; Unicorn audio lockup fixed by switching to AHI
cego1200 released AmiScreamer v1.0, an openscreamer port for 68k; testers ran it on V4SA, and danyppc got it working on a Unicorn by switching audio to AHI.

- Software rendered for 68040/060/080; a Maggie-accelerated version will follow
- On Unicorn 12205 the game locked while loading `sound.dat`; selecting AHI with an ARNE 16/32bit mix fixed it
- GOG version is DosBox plus the DOS game; michael_1260 had install script failures and used a CD image instead

❓ **Open:** Why Paula audio works on V4SA but locks on Unicorn is unexplained.
