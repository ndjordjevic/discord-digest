### External keyboards not currently supported on A6000 to save FPGA space for Maggie
Asked about wireless keyboards, r3dbug said external keyboards are not currently supported on A6000, because the core was trimmed to minimum size to make room for Maggie.

- USB was completely reworked in current cores to use much less FPGA space; a software USB stack project is ongoing.
- The A6000 keyboard lacks keys like F11/F12 on a PC keyboard, so that code was saved.
- biggun68080 said the right-side ports are Mouse and Joypad, labeled in the Unicorn manual.

### MIDI for A6000: ESP32-S3 test setup and MIDI over LAN options
veneficvs explored MIDI over LAN and proposed using an ESP32-S3 or Teensy 4.1 as an interim serial/MIDI bridge for testing; lasko_30312 said MIDI in, out and through are a must. Tjomp redirected the talk to other channels.

- rtpMidi and ipMIDI are MIDI-over-Ethernet drivers; ipMIDI is Windows only, and Mido uses rtpMidi by default.
- ESP32-S3 boards are 3.3V, so a logic level converter is needed for the extra serial ports.
- A Teensy 4.1 has extra hardware serial ports; software serial is the alternative.
