### tjomp measures lower CPU use with 080-optimized mpega.library on VaMP3
tjomp tested mpega.library on a VaMP3: the default library used 20-30% CPU, the 080-optimized one 14-22%, so tjomp dropped the planned AMMX work on it.

- Idle use was about 20% with the default library versus 15-16% with the 080 version.
- tjomp has finished AMMX optimization for jpeg, png and picture datatypes.
- kamelito suggested a list of ongoing projects to avoid duplicate efforts.
