## Top topics

### tjomp's stable AMMX RectFill and GetMsg patch make window resizing instant
tjomp reported a stable RectFill, up to 3x faster for small UI items, plus an Exec/GetMsg patch throttling redundant IDCMP_NEWSIZE messages, so windows resize instantly, even Dopus.

- Opaque window moves are slow because content is drawn live and the OS routines were designed for Aros's many graphics cards.
- tjomp earlier hit instability patching AMMX routines in via SetFunction, and suspected the e-register use as a cause.
- Removing Opaque from WBStartup fixed Dopus resizing for tommo8871, a trade-off against looks.

### biggun68080 plans 128bit 68080 core, discusses porting tjomp's AMMX GUI routines
biggun68080 is coding a new 128bit 68080 core, first on Atari, and agreed with tjomp to port the AMMX RectFill, BltBitmap and Text routines for it, possibly into the ROM.

- 128bit AMMX uses the same instruction encoding with one bit switching mode, so mnemonics change from PADD to VADD; ASMone and Vasm already support it.
- tjomp will first target 16 and 32 bit SAGA modes; biggun68080 prefers also covering 24 bit.
- biggun68080 still needs to debug the new icache before the core can be used.

❓ **Open:** Whether the routines will be tested on the 128bit core and included in the ROM.
